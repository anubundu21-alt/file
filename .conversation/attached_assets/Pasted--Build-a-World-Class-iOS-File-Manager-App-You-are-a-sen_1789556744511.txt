# Build a World-Class iOS File Manager App

You are a senior iOS product designer, React Native engineer, UX specialist, and SaaS/product monetization expert.

Build a **premium, modern iOS file manager application using React Native**.

The goal is to create a file manager that is significantly easier, cleaner, more visually engaging, and more useful than the default Apple Files experience.

The application should feel like a **premium consumer productivity app**, not a technical file browser.

---

# 1. Product Vision

Create the easiest file manager for iPhone and iPad.

Users should be able to:

* Find files instantly
* Organize files effortlessly
* Preview files beautifully
* Search intelligently
* Clean unnecessary files
* Compress and extract files
* Convert files
* Scan documents
* Protect private files
* Share files
* Manage downloads
* Connect cloud storage
* Understand where their storage is being used

The UX should require almost no learning.

Prioritize:

**Simple → Visual → Fast → Smart → Powerful**

Do NOT copy Apple's Files UI.

Create a distinctive product identity.

# 46. Important Rule

Before implementing a feature, verify whether iOS actually permits the required behavior.

Do not pretend that an iOS application has unrestricted filesystem access.

Use Apple's supported APIs and design the UX around Apple's sandbox and privacy model.

If a requested feature is impossible or restricted on iOS:

1. Explain the limitation internally.
2. Find the closest Apple-supported implementation.
3. Build the best possible UX around that implementation.
